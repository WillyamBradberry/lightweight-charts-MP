Финальный этап рефакторинга.

1. Создай `index.js` с правильным экспортом по умолчанию
2. Убедись, что всё импортируется корректно
3. Проверь, что компонент работает так же, как раньше
4. Покажи итоговую структуру папки Chart/
5. Предложи список следующих улучшений (по желанию)

После этого выполни `npm run build` и сообщи результат.
