## Visual Theme Editor 

Предназначен для настройки UI визуального оформления страницы редактирования и рисования на графиках
цветовой схемы и набора подключаемых модулей на странице.

Выполняется разработчиком перед компиляцией NPM RUN BUILD
Чтобы исключить лишние блоки кода из рабочего бандла.
## Предусмотреть: 

+ настройка бэкграунда
+ настройка вотермарка
+ при включении\отключении модуля (автоматически отключались связанные с ним иконки )
+ drawing tool - сделать набор настраиваемым, лишние инструменты (иконки) в редактре иметь возможность убрать / добавить в набор, сделать связанные примитивы отключаемыми (не добавлять при компиляции, если настроено их отсутствие в главном модуле)
## Список модулей дизайн:
+ модули построены в блочный список (сетка 3-4 колонки и группировка по смыслу)\
+ каждый модуль имеет своё описание  short \ full, в слопнутых блоках. При нажатии - открывается полное описание + скриншот (опционально)
+ ENG | RU весии UI в описаниях фич, переключается на лету
